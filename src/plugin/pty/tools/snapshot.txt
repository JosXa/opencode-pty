Captures the current visible terminal screen as clean text (ANSI-free) with cursor position, size, and a contentHash for change detection. Prefer over pty_read for TUI apps. Each snapshot has a seq number that increments on content changes. Pass `since` with a previous seq to get only changed lines instead of the full screen. Use `interleavedColors=background` on full snapshots to insert a matching background-color run row under each visible text row so highlights are visible in one call while long same-color spans stay compact.
